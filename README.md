# Bloom Atelier

Website i Bloom Atelier ndërtuar me **Nuxt.js 3** dhe **Vue 3**.

## Faqet

| Route | Faqja |
|-------|-------|
| `/` | Home |
| `/collection` | Koleksioni i Fundit |
| `/courses` | Kurset |
| `/contact` | Kontakti / Porosia |
| `/news` | Njoftime dhe Evente |

## Si niset

```bash
npm install
npm run dev
```

Hap [http://localhost:3000](http://localhost:3000)

## Tech Stack

- **Nuxt.js 3** — Vue framework
- **Vue 3** — Composition API
- **CSS** — Custom properties, responsive design
